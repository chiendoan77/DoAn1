# Database overview

Database được đề xuất là MySQL theo README. Chưa có connection config, schema, migration hoặc dữ liệu hiện có.

Schema cụ thể sẽ được chốt theo từng service sau khi API/field ownership hoàn tất. Mỗi microservice sở hữu database/schema riêng; không dùng chung schema nghiệp vụ hoặc truy cập DB service khác.
