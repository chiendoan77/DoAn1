# Frontend documentation

Frontend dùng Next.js App Router, React và TypeScript. `font-end/` có landing page, đăng ký/đăng nhập, browse provider, booking, history/review và Admin duyệt provider; API đi qua Next.js BFF. Admin user/booking và payment UI chưa triển khai. Xem [REQUIREMENTS](./REQUIREMENTS.md), [ARCHITECTURE](./ARCHITECTURE.md), [API_INTEGRATION](./API_INTEGRATION.md) và [UI_DESIGN](./UI_DESIGN.md).
