# Frontend documentation

Frontend dùng Next.js App Router, React và TypeScript trong `font-end/`; không phải Angular. `src/app/` giữ route/BFF, `src/features/` nhóm màn hình theo auth, admin, booking và marketplace, `src/shared/components/` chứa UI dùng chung, còn `src/lib/` giữ API client/DTO. Có landing/package browse, auth, provider application, booking từ package, customer profile/history/review, in-app notifications và Admin moderation qua BFF. Xem [REQUIREMENTS](./REQUIREMENTS.md), [ARCHITECTURE](./ARCHITECTURE.md), [API_INTEGRATION](./API_INTEGRATION.md) và [UI_DESIGN](./UI_DESIGN.md).
