# Frontend documentation

Frontend dùng Next.js App Router, React và TypeScript trong `font-end/`; không phải Angular. `src/app/` giữ route/BFF, `src/features/` nhóm màn hình theo auth, admin, booking và marketplace, `src/shared/components/` chứa UI dùng chung, còn `src/lib/` giữ API client/DTO. Có landing, auth, provider browse/application, booking, history/review và Admin provider approval qua BFF. Provider offering management và Admin offering approval UI chưa có trong source hiện tại. Xem [REQUIREMENTS](./REQUIREMENTS.md), [ARCHITECTURE](./ARCHITECTURE.md), [API_INTEGRATION](./API_INTEGRATION.md) và [UI_DESIGN](./UI_DESIGN.md).
