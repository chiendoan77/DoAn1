# UI design

Phân khu public/customer/provider/admin là lựa chọn điều hướng và UX, không quyết định backend domain. Dùng responsive layout, form validation, loading/empty/error states và xác nhận trước thao tác thay đổi booking.

Landing page hiện dùng hướng màu xanh đậm/nền sáng và typography cơ bản làm UI shell, chưa phải design system được duyệt. Component library, accessibility target, nội dung/trang chính xác và mức độ hoàn thiện thị giác vẫn cần chốt. Không thêm UI framework/dependency trước khi cần.
